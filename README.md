# Hackaton-hub — fichiers communs

Ce dépôt contient les fichiers appliqués par défaut à **tous** les dépôts de l'organisation
(il doit rester **public** pour que GitHub les applique) :

| Fichier | Rôle |
|---|---|
| `CONTRIBUTING.md` | Les 6 règles de l'équipe |
| `.github/pull_request_template.md` | Checklist pré-remplie dans chaque PR |
| `.github/ISSUE_TEMPLATE/tache.yml` | Formulaire « Nouvelle tâche » (ajoute l'issue au Project) |
| `NOUVELLE_COMPETITION.md` | Checklist pour ajouter une compétition |

Un dépôt qui contient son propre fichier du même type (par exemple son propre `CONTRIBUTING.md`) remplace celui-ci.

Suivi des tâches : [Project « Compétitions »](https://github.com/orgs/Hackaton-hub/projects/1).
